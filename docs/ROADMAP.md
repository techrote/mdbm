# Roadmap

## Current build

A single-source, cell-native workspace: four persistent tile identities, protected host interaction planes, strict safe theme compilation, three reference aesthetics plus three animated compositor examples, file/recovery guards, source-mapped Markdown, command parity, modal menus and scripts. The implementation report records delivered behavior and any incomplete acceptance gates.

## Stabilization

Run native Windows/macOS terminal acceptance; collect reference-machine end-to-end latency and memory traces; extend legacy compatibility only against an actual legacy schema; improve terminal-specific emoji and clipboard adapters; add broader commonmark/extension conformance corpora. Do not weaken security or silently relabel a partial terminal test as full acceptance.

## Explicitly deferred stretch goals

Kitty/iTerm2/Sixel images, theme debugger/hot reload/gallery/signatures, document tabs, workspace-wide search and backlinks, Git indicators, export, terminal pointer-shape protocols, synchronized-update extensions, arbitrary host-approved layout presets and dedicated screen-reader rendering. These are not prerequisites to the cell-native workspace and are not accidentally exposed through theme code execution.
